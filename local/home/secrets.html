Use them in a notebook or a DAG

Ask for a secret by name when you need it: always the current value, never printed. In a DAG task, import it first: from lab_spark import key_vault.

key = key_vault("WEATHER_API_KEY")       # the value
key_vault_list()                         # the names of yours
key_vault_set("WEATHER_API_KEY", "abc")  # save one from code
key_vault("db", "password")              # one field of a secret made in the vault UI
key_vault_dict("db")                     # all its fields, as a dict
